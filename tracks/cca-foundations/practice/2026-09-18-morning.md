# Practice — 2026-09-18 утро · D4 Structured Output

*Exam-pattern / practice. Не официальные вопросы Anthropic.*

## Q1. Structured Data Extraction
Нужны поля `amount`/`currency`/`due_date` без выдумок при отсутствии данных.
- ✅ Tool + `input_schema` (nullable/enum escape) + forced `tool_choice` + semantic validation
- ❌ «Отвечай только JSON» / few-shot без схемы / `tool_choice: auto`

## Q2. Few-shot bias
Классификатор почти всё → `billing` после few-shot.
- ✅ Дисбаланс меток в примерах (label imbalance)

## Q3. Schema OK, семантика нет
`end_date` &lt; `start_date` при валидной схеме.
- ✅ Targeted repair с конкретным нарушением; bounded attempts
- ❌ Blind retry / принять / backoff как для transient

## Q4. Hard constraint (email allowlist)
- ✅ PreToolUse/policy до исполнения и/или enum доменов в schema + серверная валидация
- ❌ Только system prompt / только XML-теги

## Q5. Newer API
Structured JSON в text + жёсткие tool args.
- ✅ `output_config.format` и/или `strict: true` + app-side semantic validation
