# Practice Q&A — D2 MCP / tool design (2026-09-17)

**Метка:** practice / exam-pattern. **Не** официальные вопросы Anthropic. Парафраз публичных тем и сценариев.

## Q1 — Качество описания
Агент путает `lookup_order` и `issue_refund`. Что чинить в первую очередь?
- ❌ Temperature / убрать schema / `tool_choice: none`
- ✅ Переписать descriptions: когда использовать / не использовать, required, side-effects

## Q2 — Structured error
CRM timeout → handler вернул `[]` без флага ошибки → «заказ не найден».
- ✅ `is_error: true` + «timeout, retryable» + bounded retry/escalation
- ❌ Считать пустой список = not_found / молча retry 100 раз

## Q3 — tool_choice для extraction
Нужен гарантированный вызов `extract_ticket_fields`, не prose.
- ✅ `tool_choice: {type:"tool", name:"extract_ticket_fields"}` (или `any`) + по возможности `strict: true`
- ❌ Только «ответь JSON» без tools / `tool_choice: none`

## Q4 — Distribute tools
Synthesizer получил search tools и снова ищет в вебе вместо сверки.
- ✅ Сузить `tools[]` до verify/read-only
- ❌ Только промпт «не ищи», оставив все tools

## Q5 — Claude Code MCP scope
Команде нужен общий Notion MCP.
- ✅ Project `.mcp.json` + env expansion для токена
- ❌ Local-only у одного / hardcode token в git
